# T04: Crew, resources, tools, win/lose, score

Extend `scripts/board.gd` (T02 + T03; keep their API and tests passing). Add exactly:

```gdscript
var crew: int = 3
var wood: int = 3
var gold: int = 0
var towel: bool = false          # towel of safety: the next mine costs no crewmate
var peeked: Dictionary = {}      # Vector2i -> int: numbers learned with the parrot scout
var lost: bool = false           # crew reached 0
var won: bool = false            # every safe land cell revealed

func use_detector(c: Vector2i) -> int
func use_parrot(c: Vector2i) -> int
func buy_towel() -> bool
func score() -> int
static func load_best(path: String = "user://best.json") -> int
static func save_best(value: int, path: String = "user://best.json") -> int
```

Rules:
- **Gains**, whenever a cell is newly opened (by reveal, flood fill, chord or the detector): `palm` +1 wood;
  `wreck` +50 gold and +2 wood; a chest cell +its gold (`chests[c]`).
- **Mine opened**: if `towel` is true, set it false and lose no crew; otherwise `crew -= 1`. When crew reaches 0:
  `lost = true`.
- **Won**: as soon as every land cell that is not a mine is revealed: `won = true`.
- After `won` or `lost`, `reveal`, `chord`, `toggle_flag` and the tools do nothing (return empty / -1 / false).
- **Metal detector** `use_detector(c)`: costs 3 wood. Allowed only if mines are placed, `can_reveal(c)` is true and
  wood >= 3; otherwise return -1 and change nothing. If c is a mine: flag it, return 1. If safe: open it (with
  flood fill and gains, no crew risk), return 0. One turn.
- **Parrot scout** `use_parrot(c)`: costs 2 wood. Allowed only if mines are placed, c is visible and not revealed,
  and wood >= 2 (else -1, nothing changes). Returns `number(c)` and stores it in `peeked[c]`. One turn.
- **Towel** `buy_towel()`: costs 5 wood; only if `towel` is false and wood >= 5. Returns whether it bought. One turn.
- **Score**: `gold + crew * 100 + max(0, 400 - 2 * turns)`.
- **Best score**: `load_best` returns the stored best (0 if the file is missing); `save_best` stores `value` only
  if it is higher, and returns the best after saving. JSON file `{"best": N}`.

**Files:** `scripts/board.gd` only.

**Acceptance check:** `tools/test.sh tests/test_board_core.gd tests/test_board_rules.gd tests/test_board_economy.gd`
must print `CHECK OK`.
