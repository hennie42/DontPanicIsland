# T05: The solver bot (for --autopilot)

Create `scripts/solver.gd`: a bot that plays a `Board` (scripts/board.gd) by its rules. The game's `--autopilot`
mode will use it (a later ticket), so it must only use the Board's public API, never peek at `mines` or `chests`.

Strategy (in this order):
1. Nothing revealed yet: reveal the land cell farthest from the sea (most inland; ties: the first in `b.land`).
2. Safe deductions on revealed cells with a number N, using the known mines around it F (flagged neighbours PLUS
   exploded neighbours: an exploded mine is a known mine) and the hidden unflagged land neighbours H (use
   `b.peeked` numbers the same way; skip exploded cells themselves, they have no number): if N == F and H is not empty -> `chord` (or `reveal` one of H);
   if N - F == H.size() and H is not empty -> `flag` the first of H.
3. Stuck: if `b.towel` is false and wood >= 5 -> `towel`. Else if wood >= 3 -> `detector` on the revealable cell
   with the lowest risk. Else -> `reveal` the revealable cell with the lowest risk.
   Risk of a cell = the highest (N - F) / H (F as above) over its revealed numbered neighbours; cells with no numbered
   neighbour get 0.25.

Only consider cells the board allows (`b.can_reveal`, `b.is_visible`, not flagged, ...).

**Files:** create `scripts/solver.gd`. Do not change `scripts/board.gd`.

**Acceptance check:** `tools/test.sh tests/test_solver.gd` must print `CHECK OK`. It plays 20 seeded games:
every game must end (won or lost) within 1500 moves, every move must be accepted by the board, and at least
the stated number of games must be won.
