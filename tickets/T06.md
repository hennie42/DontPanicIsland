# T06: Board view (the 3D island and the tile states)

Create `scripts/board_view.gd`: draws a `Board` in 3D and shows each cell's state. No input handling here.

```gdscript
class_name BoardView
extends Node3D

const HIDDEN_Y := 0.12          # hidden cells stand a bit higher than revealed ones (dug out)
var cells: Dictionary = {}       # Vector2i -> Node3D, one per land cell

func build(b: Board) -> void     # creates everything once
func refresh(b: Board) -> void   # updates states after every move (cheap: only toggles visibility/positions/text)
func set_numbers_billboard(on: bool) -> void   # numbers face the camera (on) or lie flat on the tile (off)
```

`build(b)`:
- Water: for every cell in `b.water`, a child `Water_<q>_<r>` = `Art.tile("water")` instance at `Hex.to_world(c)`
  (use `Art.tile("water_rocks")` where `(q * 7 + r * 13) % 11 == 0`).
- Land: for every land cell a `Node3D` child named `Cell_<q>_<r>` at `Hex.to_world(c)`, with children:
  - `Tile`: `Art.tile(terrain)` instance.
  - `Props` (Node3D at y = `Art.TILE_TOP`): palm cells get one palm (`["palm_a", "palm_b", "palm_c", "palm_d"]`,
    index `abs(q * 7 + r * 13) % 4`, rotated `(q * 37 + r * 91) % 360` degrees about y); wreck cells get
    `Art.prop("wreck")`; desert cells get `Art.prop("rocks_a")` when `abs(q + 2 * r) % 3 == 0`. Others: empty.
  - `Fog`: a Node3D at y = 0.5 with `Art.prop("cloud_small")` (and `Art.prop("cloud_big")` when `(q + r) % 2 == 0`).
  - `Dug`: `Art.tile("beach")` instance scaled `(0.94, 1, 0.94)` (a flat sand tile, a little smaller so thin
    gaps outline each revealed cell).
  - `Number`: a `Label3D`, font `res://assets/kenney/kenney-fonts/Kenney Future.ttf`, `font_size = 128`,
    `pixel_size = 0.005`, `outline_size = 18`, `outline_modulate = Color.WHITE`, lying flat
    (`rotation_degrees.x = -90`) at y = `Art.TILE_TOP + 0.03`.
  - `Peek`: like `Number` but `modulate.a = 0.55` (the parrot's peeked number on a hidden cell).
  - `Flag`: the towel flag, built from meshes: a pole (`CylinderMesh` radius 0.015, height 0.45, brown) and a
    towel of three stripes (`BoxMesh` 0.24 x 0.045 x 0.01 each, colours #e94f37, #f6f7eb, #3f88c5) at the top of
    the pole; it flaps gently (rotate the towel about the pole by `sin(time * 3 + q) * 12` degrees in `_process`).
  - `Skeleton`: `Art.prop("skeleton_a")` (gravestone of a lost crewmate).
  - `Chest`: `Art.prop("chest")`.

`refresh(b)` per land cell c:
- Fog: `Fog.visible = not b.is_visible(c)`.
- Height: revealed -> the cell node's `position.y = 0.0`; not revealed -> `HIDDEN_Y`.
- `Tile.visible = not revealed`; `Dug.visible = revealed` (the terrain tile is swapped for flat sand; `Props`
  such as palms and the wreck stay).
- `Number`: visible only if revealed, not exploded and `b.number(c) > 0`; `text = str(b.number(c))`;
  colour (`modulate`) by number: 1 #1e5bd8, 2 #2e8b3a, 3 #d63a2f, 4 #1a2a6c, 5 #7a1f1f, 6 #138a8a.
- `Peek`: visible if `b.peeked.has(c)` and not revealed; same text/colour rule with `b.peeked[c]`.
- Numbers turn with the camera: in `_process`, set every visible `Number` / `Peek` label's
  `rotation_degrees.y` to the active camera's `global_rotation_degrees.y`
  (`get_viewport().get_camera_3d()`, skip if null), keeping `rotation_degrees.x = -90` while not billboarded.
- `Flag.visible = b.flagged.has(c)`; `Skeleton.visible = b.exploded.has(c)`;
  `Chest.visible = revealed and b.chests.has(c)`.
