# T07: Camera rig (orbit, zoom, pan)

Create `scripts/camera_rig.gd`: the island camera. It orbits a target point on the ground at a fixed tilt.

```gdscript
class_name CameraRig
extends Node3D

const TILT := 50.0               # degrees above the horizon, fixed
const MIN_DIST := 4.0
const MAX_DIST := 22.0
const PAN_LIMIT := 9.0           # the target stays within this distance of the island centre (0, 0, 0)
var camera: Camera3D             # created in _ready() as a child (current = true, fov 50)
var yaw: float = 0.0             # degrees, around the y axis
var distance: float = 14.0
var target: Vector3 = Vector3.ZERO

func rotate_by(degrees: float) -> void
func zoom_by(factor: float) -> void        # distance *= factor, clamped to [MIN_DIST, MAX_DIST]
func pan_by(delta: Vector2) -> void        # moves target on the ground (y = 0) by delta.x along the camera's
                                           # right and delta.y along its forward-on-the-ground direction,
                                           # then clamps target to PAN_LIMIT from the origin
func apply() -> void                       # puts the camera at target + offset(yaw, TILT, distance), looking at target
```

The camera position: `target + Vector3(sin(yaw), 0, cos(yaw)) * distance * cos(TILT) + Vector3.UP * distance * sin(TILT)`
(angles in radians: use `deg_to_rad`), then `camera.look_at(target)`. Call `apply()` after every change.

Input (in `_unhandled_input` / `_process`; define the input actions in code with `InputMap` as in
`godot-ref/cookbook/input_actions.gd`): Q / E rotate (90 degrees per second while held); right mouse drag rotates
(0.3 degrees per pixel); mouse wheel zooms (factor 0.9 in, 1.1 out); middle mouse drag pans
(0.02 world units per pixel, scaled by distance / 14).

**Files:** create `scripts/camera_rig.gd`.

**Acceptance check:** `tools/test.sh tests/test_camera.gd` must print `CHECK OK`.
