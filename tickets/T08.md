# T08: HUD (crew, wood, gold, turns, tools)

Create `scripts/hud.gd`: the on-screen interface during play. Built in code (no .tscn needed). Sunny, readable:
font `res://assets/kenney/kenney-fonts/Kenney Future.ttf` (load it as a `FontFile` and set it in a `Theme` on the
root Control), white text with a dark outline, on rounded semi-transparent panels (`StyleBoxFlat`).

```gdscript
class_name Hud
extends CanvasLayer

signal tool_selected(tool: String)      # "detector", "parrot", "towel", or "" (back to digging)
var selected_tool: String = ""

func update_from(b: Board) -> void
func select_tool(tool: String) -> void  # sets selected_tool (a second press of the same tool deselects) and emits
```

Layout (1920x1080 viewport):
- Top-left panel: four `Label`s named exactly `Crew`, `Wood`, `Gold`, `Turns` with texts `"Crew 3"`,
  `"Wood 5"`, `"Gold 120"`, `"Turn 14"` (the numbers from the board). When `b.towel` is true the `Crew` label
  text ends with `" + towel"`.
- Bottom-centre: three `Button`s named exactly `Detector`, `Parrot`, `Towel`, texts `"Metal detector (3)"`,
  `"Parrot scout (2)"`, `"Towel of safety (5)"`. A button is `disabled` when the wood is too low; `Towel` also when
  `b.towel` is already true. Pressing `Detector` / `Parrot` calls `select_tool("detector" / "parrot")` and the
  selected button looks pressed (`toggle_mode = true`, `button_pressed`); pressing `Towel` calls
  `select_tool("towel")` (main.gd buys it immediately and then calls `select_tool("")`).
- Bottom-left: a small `Label` named `Hint`: "Left click: dig   Right click: towel flag   H: help   Esc: menu".

`update_from(b)` refreshes all texts and the disabled states, and un-presses a tool button whose tool can no longer
be afforded (then `selected_tool = ""`).
