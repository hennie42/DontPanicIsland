# T09: Game controller: input, turns, autopilot

Replace the placeholder `scripts/main.gd` (scene `scenes/main.tscn`, root `Node3D`, keep the scene as is) with the
game controller. It builds the game in code in `_ready()`:

1. Environment: a `WorldEnvironment` with a sunny `ProceduralSkyMaterial` sky (top #4aa8ff, horizon #bfe6ff),
   `tonemap_mode = Environment.TONE_MAPPER_AGX`, ambient light from the sky; a `DirectionalLight3D` sun
   (rotation_degrees (-55, 35, 0), shadows on, energy 1.2).
2. `board := Board.new()`, `view := BoardView.new()` (add, `build(board)`, `refresh(board)`),
   `rig := CameraRig.new()` (add), `hud := Hud.new()` (add, `update_from(board)`, connect `tool_selected`).
3. Parse game flags (`OS.get_cmdline_user_args()`): `--autopilot`, `--seed=N`, `--skip-intro`, `--force-lose`.
   Seed: given, else `1` with autopilot, else random. Marker `START seed=N`.

Player input (`_unhandled_input`), only while playing:
- Left click: pick the cell under the mouse:
  `Hex.ray_to_ground(rig.camera.project_ray_origin(pos), rig.camera.project_ray_normal(pos))` then
  `Hex.from_world(hit)`. With a tool selected: `detector` -> `board.use_detector(c)`, `parrot` ->
  `board.use_parrot(c)` (then `hud.select_tool("")`). No tool: if the cell is revealed -> `board.chord(c)`,
  else `board.reveal(c, seed)`.
- Right click: `board.toggle_flag(c)`.
- HUD towel: when `tool_selected` gives "towel": `board.buy_towel()`, then `hud.select_tool("")`.
- After every action that changed something: `view.refresh(board)`, `hud.update_from(board)`, marker
  `MOVE <action> <q> <r>`; when `board.won` or `board.lost`: stop input, marker
  `END result=win|lose score=<board.score()> turns=<board.turns>`, save the best score
  (`Board.save_best(board.score())`).
- Numbers billboard when zoomed out: `view.set_numbers_billboard(rig.distance > 12.0)`, checked in `_process`.

Autopilot (`--autopilot`): a `Solver`; every 0.1 s apply `solver.next_move(board)` with `Solver.apply(board, m,
seed)` and do the same refresh/marker steps. With `--force-lose`: instead of the solver, reveal a revealable mine
cell each step (the only place allowed to read `board.mines`). After `END`: wait 1 s, marker `FINISH`,
`GameEvent.quit(0)`.

**Files:** `scripts/main.gd` (rewrite). Do not change `scenes/main.tscn` unless needed.

**Acceptance check:**
`tools/play.sh 120 "START MOVE END FINISH" --autopilot --skip-intro && tools/play.sh 60 "START END FINISH" --autopilot --skip-intro --force-lose`
must end with `CHECK OK`.
