# T13: Music and sound effects

1. Write `tools/make_music.py`: a cheerful 16-bar procedural loop (steel drum + ukulele feel, ~110 bpm, C major,
   I-V-vi-IV), rendered to `audio/music_loop.wav` (44.1 kHz, 16-bit, stereo, 30-40 s, loops seamlessly: same
   sample value at start and end, no click). Use `tools/studio_audio.py` (read it first: it has the synth helpers)
   and numpy. Peaks below -1 dBFS. Run it, and import with `studio godot-import`.
2. Create `scripts/sfx.gd` (class `Sfx`, extends `Node`): creates the audio buses "Music" and "SFX" if missing,
   plays the music loop on "Music" (looping), and has `play(name: String)` for: `dig`, `flag`, `boom`, `coin`,
   `click`, `ufo`, `drop`, `tool`, `lose`, `win`. Use the files in `assets/INDEX.md` section `sound-effects`
   (dig: footstep_grass_000/_002 alternating, flag: cloth1, boom: explosion-a, coin: coin-a, click: click_001,
   ufo: spaceEngineLow_000, drop: drop_001, tool: powerUp2, lose: lose-a, win: jingles_HIT00).
3. Wire it in `scripts/main.gd` (and intro/ending/menu if they exist): dig on reveal, coin when gold went up, boom
   on a mine, flag on flag toggles, tool on tool use, click on buttons, ufo + drop in the intro, win/lose at the end.

Markers: `MUSIC_START`, `SFX <name>` on every play.

**Files:** create `tools/make_music.py`, `audio/music_loop.wav`, `scripts/sfx.gd`; edit `scripts/main.gd` (+ the
scripts above, only to call `Sfx`).

**Acceptance check:** `test -f audio/music_loop.wav && tools/play.sh 150 "MUSIC_START SFX END FINISH" --autopilot --skip-intro`
must end with `CHECK OK`.
