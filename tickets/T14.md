# T14: The camp, the crew and beach dressing

Create `scripts/decor.gd` (class `Decor`, extends `Node3D`) and use it from `scripts/main.gd`.

```gdscript
func build(b: Board, view: BoardView) -> void      # static beach dressing, once
func place_camp(b: Board, first: Vector2i) -> void  # after the first reveal: the camp on the landing cell
func update_crew(b: Board) -> void                  # after every move: crew figures vs skeletons
```

- **Beach dressing** (build): on beach cells only, deterministic by cell hash (`abs(q * 31 + r * 17) % N`):
  ~6 beach balls (`ball_red` / `ball_yellow`), ~4 buckets with a shovel next to them (`bucket`, `shovel`), ~5 crabs
  (`crab`, they wander slowly back and forth over 0.2 units), 3 beach umbrellas (build from meshes: a `CylinderMesh`
  pole 0.5 tall and a cone canopy `CylinderMesh` top_radius 0.02 bottom_radius 0.35 height 0.15, striped by two
  colours: use 8 canopy slices or a simple two-colour material), a parrot (`parrot`) on one palm top, a rowboat
  (`rowboat`) in the water next to one beach cell. Props sit at `Art.TILE_TOP` on their cell, offset from the
  centre by up to 0.25 so they don't hide the numbers; parent them under the cell's `Props` node so they move with
  it.
- **Camp** (place_camp): on the landing cell: `camp_flag`, `campfire`, `barrel`, `crate`; and the 3 crew figures
  (`crew_a`, `crew_b`, `crew_c`) standing around the fire, playing their idle animation (an `AnimationPlayer` in
  the model or from the rig file `Rig_Medium_General.glb` in `assets/INDEX.md`; if no animation fits, a gentle
  bob).
- **Crew** (update_crew): when a crewmate is lost, the figure at the camp is replaced by `skeleton_a` lying down
  (rotation x 90 degrees), and the camp flag lowers a third.

Markers: `CAMP q r`, `CREW n`. With `--force-lose` the log must show `CREW 2`, `CREW 1`, `CREW 0`.

**Files:** create `scripts/decor.gd`; edit `scripts/main.gd`.

**Acceptance check:** `tools/play.sh 150 "CAMP END FINISH" --autopilot --skip-intro && tools/play.sh 90 "CAMP CREW END FINISH" --autopilot --skip-intro --force-lose`
must end with `CHECK OK`.
