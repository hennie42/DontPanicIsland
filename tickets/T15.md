# T15: Exports (Linux and web) and the packaged autopilot

Make the game export and run outside the editor.

1. `studio godot-export linux` and `studio godot-export web` (presets exist in `export_presets.cfg`; fix them only if
   the export fails, e.g. include `data/*.json` in the resources: `include_filter="data/*.json"`).
2. The Linux build must play itself: `studio run-export 150 --headless --autopilot --skip-intro` logs `START`,
   `END` and `FINISH`.
3. Check that `user://best.json` writing works in the export (the END step saves it).

**Files:** `export_presets.cfg` only if needed; nothing else unless the export reveals a bug (then fix the bug in
the script it points to, minimally).

**Acceptance check:** `studio godot-export linux && studio godot-export web && test -f build/web/index.html &&
studio run-export 150 --headless --autopilot --skip-intro | tee /dev/stderr | grep -q GAME_FINISH && echo CHECK OK`
must end with `CHECK OK`.
