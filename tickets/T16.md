# T16: Ambient life (palms sway, fog drifts, gulls, camp smoke)

Create `scripts/ambience.gd` (class `Ambience`, extends `Node3D`). Edit `scripts/decor.gd` and `scripts/main.gd` only
where this ticket says.

```gdscript
func build(b: Board, view: BoardView) -> void   # once, after the board view and decor are built
func add_smoke(pos: Vector3) -> void            # smoke column at a world position (the camp fire)
```

**main.gd:** add `var ambience: Ambience`. In `_ready`, right after `decor.build(board, view)`:
`ambience = Ambience.new()`, `add_child(ambience)`, `ambience.build(board, view)`. In `_after_board_change`, right
after `decor.place_camp(board, c)`: `ambience.add_smoke(decor.fire_position())`.

**decor.gd:** add `func fire_position() -> Vector3`: the campfire's `global_position` once the camp is placed,
`Vector3.INF` before. (Keep a reference to the campfire node that `place_camp` creates.)

**Ambience** (one `_process` loop; collect the nodes once in `build`, store them in typed arrays):
- **Palms sway.** For every land cell whose terrain is `"palm"`: the palm is the first child of
  `view.cells[c].get_node("Props/TerrainProp")`. Each frame set its `rotation_degrees.x = sin(t * 1.1 + ph) * 2.5`
  and `rotation_degrees.z = cos(t * 0.9 + ph) * 2.0`, leaving `rotation_degrees.y` as it is (the view sets it).
  `t = Time.get_ticks_msec() / 1000.0`, `ph = float(abs(c.x * 13 + c.y * 7) % 100) * 0.37`.
- **Fog drifts.** For every land cell's `Fog` node (`view.cells[c].get_node("Fog")`): each frame
  `position.y = 0.5 + sin(t * 0.7 + ph) * 0.05` and `rotation_degrees.y = sin(t * 0.25 + ph) * 12.0`.
- **Gulls.** Three children named exactly `Gull_0`, `Gull_1`, `Gull_2` (Node3D), each built from meshes: a body
  (`CapsuleMesh` radius 0.04, height 0.18, rotated to lie along its local z) and two wings (`BoxMesh`
  0.22 x 0.01 x 0.07, one each side of the body, pivoting at the body: put each wing mesh under its own Node3D
  hinge at the body side, offset by half its width). Material: `StandardMaterial3D`, white `#f4f6f8`; wing tips
  may be grey. The wings flap: hinge `rotation_degrees.z = ±sin(t * 6.0 + i) * 25.0` (mirrored). Each gull circles
  the island centre (the average of `Hex.to_world(c)` over `b.land`, y = 0): radius `5.0 + i * 1.3`, height
  `3.0 + i * 0.4`, angular speed `0.25 + i * 0.07` rad/s, gull 1 the other way round; it faces its direction of
  travel (`look_at` the next point on its circle, or set `rotation.y` from the tangent).
- **Smoke.** `add_smoke(pos)`: if `pos == Vector3.INF` do nothing. Otherwise a `CPUParticles3D` named exactly `Smoke`
  (a child of the Ambience) at `pos + Vector3(0, 0.15, 0)`: `amount = 24`, `lifetime = 2.5`, `emitting = true`,
  `direction = Vector3.UP`, `spread = 12`, `gravity = Vector3(0, 0.15, 0)`, `initial_velocity_min/max = 0.2/0.35`,
  `scale_amount_min/max = 0.6/1.0` with a `scale_amount_curve` (Curve: 0.4 at 0 rising to 1.0 at 1), `color_ramp` a
  Gradient from `Color(0.85, 0.85, 0.85, 0.55)` to `Color(0.9, 0.9, 0.9, 0.0)`, `mesh` a `SphereMesh` (radius 0.06,
  height 0.12) with an unshaded, alpha-transparent `StandardMaterial3D` that uses vertex colour as albedo
  (`vertex_color_use_as_albedo = true`).
- At the end of `build`: marker `GameEvent.marker("LIFE", "gulls=3 palms=%d" % palm_count)`.
