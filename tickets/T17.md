# T17: Dig effects (ripple, pop, sand bursts)

Opened tiles should not just switch: they pop down in a ripple outwards from the click, with a puff of sand, and
their numbers pop in. Edit `scripts/board_view.gd` and `scripts/main.gd`.

**board_view.gd:** change the signature to `func refresh(b: Board, origin: Variant = null) -> void`.
- Everything `refresh` sets today (visibility of Fog, Tile, Dug, Number, Peek, Flag, Skeleton, Chest, TerrainProp,
  outlines, label texts and colours, the cell height) stays exactly as it is and is set **at once**: tests check the
  state right after `refresh`. Only motion is added on top.
- Keep `var _shown: Dictionary = {}` (Vector2i -> true): the cells that were revealed at the previous refresh. The
  newly revealed cells are those in `b.revealed` but not in `_shown`. Update `_shown` at the end of every refresh.
- If `origin` is a `Vector2i` (not null), animate each newly revealed cell `c` with delay
  `d = Hex.distance(origin, c) * 0.045` seconds:
  - its cell node starts at `position.y = HIDDEN_Y` and tweens to `0.0` over 0.22 s (`Tween.TRANS_BACK`,
    `Tween.EASE_OUT`), starting after `d` (`tween_interval(d)` or `set_delay(d)`);
  - its scale starts at `Vector3(1.12, 0.75, 1.12)` and tweens to `Vector3.ONE` over 0.3 s, also after `d`;
  - if its `Number` label is visible: label scale `Vector3.ZERO` -> `Vector3.ONE` over 0.25 s after `d + 0.1`
    (`TRANS_BACK`, `EASE_OUT`).
  Use one `create_tween()` per cell (tweens bound to the view); kill a cell's running tween before starting a new
  one for it.
- Sand bursts: for the newly revealed cells nearest to `origin` (at most 14; sort by `Hex.distance`), add a one-shot
  `CPUParticles3D` named exactly `Burst` as a child of the cell node at `position.y = Art.TILE_TOP`: `amount = 10`,
  `lifetime = 0.6`, `one_shot = true`, `explosiveness = 1.0`, `emitting = true`, `direction = Vector3.UP`,
  `spread = 60`, `initial_velocity_min/max = 0.8/1.6`, `gravity = Vector3(0, -6, 0)`, `scale_amount_min/max =
  0.5/1.0`, `color = Color("#e8c79a")`, `mesh` a `BoxMesh` 0.04 x 0.04 x 0.04 with a `StandardMaterial3D` using
  vertex colour as albedo. Start each burst when its cell's delay has passed; free it 1.0 s after it started
  (`get_tree().create_timer(...)`, and check `is_instance_valid` before freeing).
- If `origin` is null: no animation, no bursts (the same instant result as today).

**main.gd:** in `_after_board_change(move)`, call `view.refresh(board, move.get("cell"))` for the actions `reveal`,
`chord` and `detector`, and `view.refresh(board)` otherwise. Nothing else changes.

**Files:** `scripts/board_view.gd`, `scripts/main.gd`.
