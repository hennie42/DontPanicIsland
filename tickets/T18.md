# T18: Mine and towel effects (flash, smoke, sparks, camera shake, towel bounce)

Create `scripts/fx.gd` (class `Fx`, extends `Node3D`). Edit `scripts/camera_rig.gd`, `scripts/board_view.gd` and
`scripts/main.gd` only where this ticket says.

```gdscript
# fx.gd
func setup(rig: CameraRig, hud: Hud) -> void
func explosion(pos: Vector3) -> void        # a mine went off at this world position (tile top)
```

**Fx.explosion(pos)** (all nodes children of the Fx):
- an `OmniLight3D` named exactly `Flash` at `pos + Vector3(0, 0.6, 0)`: `light_color = Color("#ffb347")`,
  `omni_range = 4.0`, `light_energy = 6.0`, tweened to 0 over 0.35 s, then freed (`queue_free` at the end of the
  tween);
- a one-shot `CPUParticles3D` named exactly `Smoke`: 30 particles, `lifetime = 1.2`, `explosiveness = 0.9`,
  `direction = Vector3.UP`, `spread = 45`, `initial_velocity_min/max = 0.6/1.4`, `gravity = Vector3(0, 0.3, 0)`,
  `color = Color(0.25, 0.25, 0.27, 0.8)`, mesh a `SphereMesh` radius 0.07 with an alpha-transparent material using
  vertex colour; freed after 1.6 s;
- a one-shot `CPUParticles3D` named exactly `Sparks`: 20 particles, `lifetime = 0.5`, `explosiveness = 1.0`,
  `spread = 180`, `initial_velocity_min/max = 2.0/3.5`, `gravity = Vector3(0, -9, 0)`, `color = Color("#ffcf4a")`,
  mesh a `BoxMesh` 0.03 x 0.03 x 0.03, unshaded vertex-colour material; freed after 1.0 s;
- `rig.shake(0.18, 0.4)`;
- marker `GameEvent.marker("FX", "boom")`.
(Free with timers or tween callbacks; check `is_instance_valid` before freeing.)

**camera_rig.gd:** add `var shake_offset: Vector3 = Vector3.ZERO` and `func shake(strength: float, seconds: float)
-> void`. While a shake runs, every frame set `shake_offset` to a random vector (each axis
`randf_range(-1, 1)`) times `strength * remaining / seconds`, and call `apply()`; when it ends set
`shake_offset = Vector3.ZERO` and call `apply()` once more. In `apply()`, add `shake_offset` to the camera's
`global_position` (after the existing position maths, before `look_at`; look at `target + shake_offset * 0.5` so the
view jolts instead of turning). Nothing else in the rig changes.

**board_view.gd:** add `func bounce_flag(c: Vector2i) -> void`: the cell's `Flag` node pops in: scale
`Vector3(0.2, 0.2, 0.2)` -> `Vector3(1.2, 1.2, 1.2)` (0.12 s) -> `Vector3.ONE` (0.12 s), and at the same time
`position.y` from 0.4 to 0.0 over 0.2 s (`TRANS_BOUNCE`, `EASE_OUT`). It must end exactly at scale ONE, y 0.

**main.gd:** add `var fx: Fx`; in `_ready` after the rig and hud exist: `fx = Fx.new()`, `add_child(fx)`,
`fx.setup(rig, hud)`. In `_after_board_change(move)`, after the view refresh:
- for each cell in `move.get("opened", [])` (and the move's `cell` for `chord` and `detector`) that is in
  `board.exploded` and was not exploded before this move: `fx.explosion(Hex.to_world(c) + Vector3(0, Art.TILE_TOP, 0))`
  (keep a copy of `board.exploded.keys()` from the previous move to know what is new; at most one explosion per
  cell);
- if the action is `flag` and `board.flagged.has(cell)`: `view.bounce_flag(cell)` and marker
  `GameEvent.marker("FX", "towel")`.
