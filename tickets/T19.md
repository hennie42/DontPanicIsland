# T19: Treasure effects (sparkle, coins fly to the counter, the counter ticks up)

Edit `scripts/fx.gd`, `scripts/hud.gd` and `scripts/main.gd` only where this ticket says.

**fx.gd:** add `func treasure(pos: Vector3, gold: int) -> void`:
- a one-shot `CPUParticles3D` named exactly `Sparkle` (child of the Fx) at `pos + Vector3(0, 0.25, 0)`: 24 particles,
  `lifetime = 0.8`, `explosiveness = 0.8`, `direction = Vector3.UP`, `spread = 70`, `initial_velocity_min/max =
  0.6/1.4`, `gravity = Vector3(0, -1.5, 0)`, `color = Color("#ffd23f")`, mesh a `SphereMesh` radius 0.025 with an
  unshaded vertex-colour material; freed after 1.2 s (check `is_instance_valid`);
- `hud.fly_coins(rig.camera.unproject_position(pos), clampi(gold / 10, 3, 8))`;
- marker `GameEvent.marker("TREASURE", str(gold))`.

**hud.gd:**
- `func fly_coins(from: Vector2, n: int) -> void`: `n` small gold coins, each a `Panel` named exactly
  `Coin_<i>` (`Coin_0`, `Coin_1`, ...; set `name` before `add_child` and pass `true` as `force_readable_name`), size
  28 x 28, a `StyleBoxFlat` with `bg_color = Color("#ffd23f")`, `border_color = Color("#b8860b")`, border width 3,
  corner radius 14, `mouse_filter = Control.MOUSE_FILTER_IGNORE`, added under the HUD's root control. Coin `i`
  starts at `from` plus a small random offset (up to 24 px), waits `i * 0.06` s, then tweens its `position` to the
  centre of the gold label (`_gold_label.get_global_rect().get_center()` minus half the coin size) over 0.55 s
  (`TRANS_QUAD`, `EASE_IN`) and frees itself at the end.
- `func count_gold(from: int, to: int, seconds: float) -> void`: the gold label counts up from `from` to `to`
  (`create_tween().tween_method(...)`, text `"Gold %d"` with the rounded value), ending exactly on `"Gold %d" % to`.
  A new call kills the previous count.
- `update_from(b)` stays as it is (it sets `"Gold %d" % b.gold` at once: `tests/test_hud.gd` checks that).

**main.gd:** in `_after_board_change(move)`, after `hud.update_from(board)`: if `board.gold > _last_gold`
(the existing coin-sound check), call `hud.count_gold(_last_gold, board.gold, 0.8)`, and for every cell in
`move.get("opened", [])` that is in `board.chests`, call
`fx.treasure(Hex.to_world(c) + Vector3(0, Art.TILE_TOP, 0), board.chests[c])`. Do this before `_last_gold` is
updated.

**Files:** `scripts/fx.gd`, `scripts/hud.gd`, `scripts/main.gd`.

**Acceptance check:** `tools/test.sh tests/test_hud.gd && tools/probe.sh tests/play_treasure.tscn 90 "TREASURE OK" --skip-intro && tools/play.sh 150 "TREASURE START END FINISH" --autopilot --skip-intro`
(read `tests/play_treasure.gd`: it calls `fx.treasure` and `hud.count_gold` and checks the sparkle, the coins flying
to the counter, the counting and the clean-up).
